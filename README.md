## About

Welcome to my collection of **Windhawk mods and Windows customization projects**.

This repository contains my personal experiments, modifications, and improvements for Windows. My goal is to make Windows more customizable, intuitive, and enjoyable to use while preserving the functionality and stability of the operating system.

Projects focus on areas such as:

- **User Interface** — Start Menu modifications, visual improvements, and interface customization.
- **Productivity** — Small enhancements that make everyday Windows interactions more convenient.
- **Performance** — Lightweight modifications designed to minimize unnecessary resource usage.
- **Windows Personalization** — Custom behaviors, interface tweaks, and alternative user experiences.

Each project may have its own design goals, implementation details, requirements, and development status.

## Requirements

Requirements depend on the individual mod. In general, you may need:

- A supported Windows version, as specified by the mod.
- [Windhawk](https://windhawk.net/) installed on your system.
- The appropriate permissions and dependencies required by the individual project.

Always review a mod's source code, metadata, and instructions before installing it.

## Installation

1. Install Windhawk from the [official website](https://windhawk.net/).
2. Open the desired `.wh.cpp` source file in this repository.
3. Review the mod's metadata and any installation instructions.
4. Create a new mod in Windhawk and paste the complete source code into its editor.
5. Compile and enable the mod.
6. Test its functionality and disable it if you encounter unexpected behavior.

Some projects may require additional setup. Follow the instructions provided with each mod.

## Development Status

Projects may be in different stages of development:

- **Experimental** — Under active development and testing.
- **In Development** — Features are being implemented or refined.
- **Stable** — Tested sufficiently for the intended use, with known limitations documented.

A project should not be considered stable solely because it compiles successfully. Compatibility and runtime behavior depend on the Windows version, system configuration, and the mod's implementation.

## Compatibility & Safety

Windhawk mods can interact with Windows processes and internal APIs. As a result, certain modifications may become incompatible with Windows updates or other system customizations.

Please keep the following in mind:

- Review the code before enabling unfamiliar modifications.
- Keep Windhawk and Windows up to date.
- Test experimental mods carefully.
- Disable a mod if it causes crashes, unexpected behavior, or compatibility issues.
- Keep a way to disable problematic mods and recover your normal Windows environment.

**Use experimental modifications at your own risk.** No mod is guaranteed to work on every Windows configuration.
